Coverage numbers must be measured using `scripts/go-coverage-table.sh` on a fresh `coverage.out` from `go test ./internal/... -count=1 -coverprofile=coverage.out`.

**The script is correct.** It reads Go coverprofile format `numStmts count` correctly: group(4) = numStmts, group(5) = count. Do NOT swap these fields — that was a mistake in Session 030 that produced fake 100% coverage by making uncovered blocks invisible.

**How to apply:** Always regenerate coverage.out fresh. Always use `scripts/go-coverage-table.sh`. The per-package uncovered counts are stable across runs; the covered/total numbers vary slightly due to Go test execution order. Compare uncovered counts, not just percentages. See `docs/coverage-measurement.md` for full instructions.

**Session 030 baseline numbers:** Main (fresh): 5911/6002 (91 uncov). Branch 020-td-sprint: 5956/6047 (91 uncov). 0 new uncovered. The report header's previous 5816/5898 (82 uncov) was from a stale profile at a different time — the 82→91 difference is from test execution order, not code changes.
