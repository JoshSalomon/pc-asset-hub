### kind-deploy.sh rebuild() doesn't rebuild the webhook plugin
The `rebuild()` function in `scripts/kind-deploy.sh` only rebuilds the 3 main images (API, UI, operator). The webhook plugin build was in `deploy_resources()` only. Fixed by extracting `rebuild_plugin()` called from both paths.

### Podman + Kind image loading requires tarball
`kind load docker-image` doesn't work with podman. Must use: `podman save` → tarball → `kind load image-archive`. Same pattern as `load_images()`.

### CRD must be updated before applying CRs with new fields
When adding fields to a CRD (e.g., `attributeMappings`), the CRD must be applied to the cluster BEFORE any CR that uses the new field. Otherwise K8s strict validation rejects the CR with "unknown field".

### Operational catalog page URL in production
In the deployed UI (served via nginx), operational catalog pages are at `/catalogs/{name}`, NOT `/operational/catalogs/{name}`. The `/operational` prefix is only for development with Vite's multi-entry setup. System tests must use `/catalogs/{name}`.
